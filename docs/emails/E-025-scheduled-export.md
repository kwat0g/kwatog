# E-025 — scheduled export

## Source and behavior

- `exports:run-due` runs each due schedule and creates the artifact through the shared export registry and spreadsheet service.
- The report uses the saved columns and filters; owner permission and row scope are checked at generation and again before queue processing.
- Delivery goes only to the active schedule owner's current email. Legacy persisted recipient lists are ignored. Shared-recipient delivery stays disabled until each recipient's access to the exact row scope can be proven.
- The attachment is the private artifact generated by the selected export. Filenames are sanitized, empty files are rejected, and artifacts above 25 MiB are rejected.
- Queue dispatch is after commit. The mailable revalidates schedule ownership, active status, current recipient, module permission, columns, filters, and authorization context before attaching the file.
- Retries of the same due occurrence reuse a stable delivery key derived from schedule ID and `next_run_at`, so duplicate dispatches are suppressed by the shared delivery ledger.

## Content

Subject includes the configured email brand, report name, and ready status. The message identifies report area, generation time, exact filename, and format. It says that the selected export file is attached and links to the authenticated SPA schedule page. The CTA is navigation only.

Module identifiers are converted to a readable label; the email does not display raw module keys. Blade escapes user-controlled report name and filename. CR/LF is removed from the subject value.

## Presentation and privacy

Uses the shared Laravel Markdown shell, configured company branding, light/dark logos, responsive layout, preheader, VML-safe CTA, and generated plain-text alternative. It includes no report rows or extra sensitive fields in the body. The attachment remains the export source of truth.

## Open items

- Shared-recipient delivery needs a recipient picker backed by active users and per-recipient row-scope validation. Until then, only the schedule owner receives the export.
- Check applicable confidential financial and personal-data exports with the company's accountant, HR, legal contact, and data protection officer before delivery.
- Real email clients remain unverified.
