# Error Handling & Frontend Risk Audit Findings

Status: initial discovery pass; this log is being expanded as the module-by-module audit continues. Locations use repository-relative paths and line numbers from the audited working tree.

Severity: **workflow-blocking** means a user cannot complete a workflow or a security/integrity boundary is at risk; **UX-degrading** means the workflow can continue but failure information or reliability is materially reduced; **cosmetic** means a consistency or maintainability issue without immediate workflow impact.

## Coverage notes

- `api/bootstrap/app.php:95-176` has deliberate JSON renderers for business rules, authorization, HTTP errors, and sanitized unexpected 500s. Laravel's normal exception reporting remains in place for uncaught exceptions; EH-001 is a confirmed swallowed-exception exception to that path.
- `spa/src/lib/formErrors.ts` already provides shared `reportMutationError`; many pages still implement local `onError` toast strings. The app's shared utility is a consolidation point, not evidence that all error paths are consistent.
- Route files use lazy page imports (310 `lazy(` occurrences under `spa/src/routes` at the time of this pass); the initial bundle-splitting category is not currently a confirmed finding.
- EH-001 was fixed on an isolated branch and submitted separately as PR #152; its focused regression test passed (1 test, 4 assertions).
- The repository contains 23 Laravel module directories plus common/public areas. The requested 17 business modules do not map one-to-one to those technical directories; audit coverage will follow all feature routes and their frontend/API code, including shared code and portal/mobile surfaces.
- `spa/scripts/audit-api-routes.mjs` reports 14 stale scope-manifest entries; these are tracked as FE-015. The dynamic browser route audit could not run in this environment because `playwright-core` is not installed, so browser-only route mounting/fetch behavior remains a follow-up check.
- A final static scan on 2026-09-25 still finds 97 page-level generic mutation toasts, 24 vague query error descriptions, and 108 `per_page` values of 100/200/500. These are consolidation work (shared mutation helper, `QueryErrorState` subjects, and server-search selectors), not evidence that the targeted fixes above are incomplete.
